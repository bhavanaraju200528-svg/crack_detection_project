# crack_detection_project
An AI-powered crack detection system built using deep learning (ResNet50) to identify cracks in pavement and structural surfaces, enabling early damage detection and safety analysis.
# 🧠 Crack Detection using Deep Learning (ResNet50)

## 📌 Overview
This project focuses on detecting cracks in pavement and structural surfaces using deep learning techniques. The model is built using ResNet50 and helps in identifying damaged regions for early safety analysis.

---

## 🚀 Features
- Crack detection using ResNet50
- Image preprocessing and classification
- Bounding box visualization for crack areas
- Grad-CAM heatmaps for model explainability

---

## 🛠️ Technologies Used
- Python
- PyTorch
- OpenCV
- NumPy
- Matplotlib
